# Data dictionary

All values are simulated for methodological demonstration.

| Field | Description |
|---|---|
| farm_id | Stable fictional farm identifier |
| country | Simulated Finland/Sweden designation |
| region | Simulated geographic grouping |
| year | Observation year (2000–2023) |
| hectares | Simulated farm land area |
| owner_id | Fictional owner identifier in ownership history |
| previous_owner | Owner recorded in the preceding observation |
| gap_in_history | Flag where sequential observation years are not consecutive |
| transfer_year | Synthetic registered year of ownership change |
| transfer_mode | Registry classification: inheritance, gift, market_sale, other |
| family_transfer | Binary family relationship indicator from simulated registry |
| classification_source | Synthetic source metadata |
| investment_rate_pct | Simulated farm investment rate (%) |
| productivity_index | Simulated productivity index |
| sweden_post_2005 | Contextual indicator, not identified causal treatment |
| event_time | Year relative to a transfer |
| post_transfer | One from transfer year onward |
| treated_ever | One for farms with an observed transfer |

Owner identifiers and relationship classifications are invented; no personal records were used.
